+-[man calgen]-file vs subscription+

Live feed (subscription)

When the search finds a public .ics feed published by the organiser or a calendar site, subscribing to it keeps your calendar in step: changed dates and new sessions arrive on their own. The SUBSCRIBE panel gives you the webcal:// address and a Google Calendar link.

Apple Calendar: File › New Calendar Subscription, paste the address, set auto-refresh to every day. iPhone: Settings › Apps › Calendar › Calendar Accounts › Add Account › Other › Add Subscribed Calendar.

Generated file (.ics)

When no public feed exists, CalGen builds the file itself from the dates it found. Open it and your calendar app adds every event. Each event keeps the same ID between builds, so if dates change, rebuild here and open the new file: Apple Calendar and Outlook update the existing events instead of making copies.

To turn a generated file into a subscription, upload it somewhere with a public address (a GitHub gist's raw link or a web host) and subscribe to that address.

Status colours

[ OK ] published by the organiser · [PROV] provisional or subject to contract · [ TBA ] not announced yet, so nothing is added to the file.
